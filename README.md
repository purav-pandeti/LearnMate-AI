# LearnMate AI – Personalized Learning Assistant

An AI-powered personalized learning assistant developed to support **UN Sustainable Development Goal 4: Quality Education**.

## About the Project

LearnMate AI is an intelligent educational chatbot designed to make learning more accessible, interactive, and personalized. It helps students understand difficult concepts, clear doubts, organize study schedules, and evaluate their knowledge through quizzes.

The chatbot is powered by Botpress and integrated into a responsive website built using HTML, CSS, and JavaScript.

## Problem Statement

Students often face difficulties understanding complex academic concepts, getting timely answers to their doubts, and organizing their study schedules. Traditional learning resources may not always provide personalized, interactive assistance.

LearnMate AI aims to address these challenges through an AI-powered learning companion.

## Features

### 1. AI Tutor
- Explains academic concepts in simple language.
- Provides step-by-step explanations.
- Uses examples to improve understanding.

### 2. Doubt Solver
- Answers subject-related questions.
- Provides explanations for difficult concepts.
- Supports interactive learning.

### 3. Study Planner
- Creates personalized study schedules.
- Helps students organize learning activities.
- Supports better time management.

### 4. Quiz Generator
- Generates multiple-choice questions.
- Evaluates student answers.
- Provides explanations and final scores.
